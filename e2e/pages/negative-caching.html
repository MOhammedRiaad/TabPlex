Caching missing names

Negative caching means a resolver remembers that a name does not exist. Without it, every typing mistake or misconfigured domain would send a new question to the authoritative server each time someone asked for that name.

How long a miss is kept

The authoritative server tells the resolver how long to keep a negative answer. That period is taken from the zone's SOA record, and resolvers usually cap it at a few hours so that a newly created name becomes visible soon.

Why it helps

Negative answers are common for mail servers and for software that checks many optional names. Keeping them for a short time saves a large number of questions, while still letting a new name appear quickly after it is created.
