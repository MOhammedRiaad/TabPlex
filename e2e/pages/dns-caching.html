DNS caching explained

DNS caching keeps the answers a resolver has already received so that a repeated lookup for the same name does not need another round trip across the internet. Caching happens in several places at once: the browser, the operating system, the home router and the recursive resolver run by an internet provider.

Where answers are stored

When a resolver receives an answer, it stores the record in memory together with the time it arrived. The next client that asks for the same name gets the stored answer at once, which makes most page loads start faster. A busy resolver can answer thousands of such questions every second from its cache alone.

Why caching matters

An uncached lookup can take tens of milliseconds, and a single web page may need dozens of lookups for its images, scripts and fonts. Caching removes most of that waiting. It also protects authoritative servers from answering the same question again and again.
